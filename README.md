# 🚚 Logistics Operations Analytics Dashboard (Power BI)

A data-driven analysis of logistics operations focusing on order performance, driver efficiency, and vehicle utilization using Power BI.

---

## 📌 Project Overview

This project analyzes logistics data using interactive Power BI dashboards to uncover insights into delivery operations.  
It integrates data from orders, drivers, vehicles, and hubs to provide a complete operational view.

The dashboards help answer key business questions such as:
- How are delivery operations performing over time?
- Which drivers and vehicles are most efficient?
- Which hubs handle the highest workload?
- How effectively is the fleet being utilized?

---

## 🎯 Objectives

- Analyze order trends and delivery performance  
- Evaluate driver productivity and efficiency  
- Monitor vehicle utilization and fleet performance  
- Identify operational inefficiencies  
- Provide data-driven business insights  

---

## 🛠 Tools Used

- Power BI  
- Microsoft Excel  
- Power Query  
- DAX

## 📈 Key Insights

- High delivery success rate indicates strong operational efficiency  
- Vans are the most utilized vehicle type  
- Certain hubs handle significantly higher order volumes  
- Driver performance varies across the workforce  
- Fleet utilization is high, indicating efficient resource usage  

---

## 💡 Business Recommendations

- Balance driver workload to improve efficiency  
- Optimize resource allocation at high-demand hubs  
- Monitor vehicle maintenance to reduce downtime  
- Use demand trends for better fleet planning  
- Implement route optimization to reduce delivery time
